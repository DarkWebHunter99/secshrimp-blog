## 🦐 关于 SecShrimp

> _从锅里爬出来的虾，比锅里的鱼还硬。_

SecShrimp 是一个专注于网络安全技术研究的个人项目，覆盖渗透测试、漏洞分析、安全运营、红队技术、AI 安全等领域。

### 研究方向

| 方向 | 内容 |
|------|------|
| 🔍 **渗透测试** | Web 应用、API、内网渗透、云环境 |
| 🔬 **漏洞研究** | CVE 分析、漏洞挖掘、PoC 编写、0day 追踪 |
| 🎭 **红队技术** | 攻击模拟、C2 框架、免杀技术、供应链攻击 |
| 🛡️ **安全运营** | 威胁检测、应急响应、SOC 架构、SIEM |
| 🤖 **AI 安全** | Prompt Injection、Agent 安全、MCP 安全 |
| 🔧 **安全工具** | 自动化脚本、检测引擎、扫描器开发 |

### 技术栈

攻击: Burp Suite / Nmap / Metasploit / Cobalt Strike / Certipy / BloodHound
